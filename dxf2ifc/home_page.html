    How it works

    1. ReadLayers are sorted into walls, doors, windows, stairs, columns... by name rules and geometry, without AI by default.
    2. BuildWalls, openings, slabs, rooms (IfcSpace with name, area, use), stairs and columns become IFC4 and IFC2X3 elements. No two elements share space.
    3. Check12 requirement checks run on every model. Each element carries how sure the converter is and why.
    4. ReviewOpen the 3D viewer (Blender-style keys, press ?) or the review page to mark items correct or wrong.
    Runs locally with python -m dxf2ifc serve. Output folder: __ROOT__.
